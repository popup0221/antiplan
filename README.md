# 🍸 Anti Plan

**No plan? Anti plan!**

자주 가는 칵테일 바에서 매번 뭘 마실지 고민하다가 만든 칵테일 추천 서비스입니다.

몇 가지 질문에 답하면 취향에 맞는 칵테일을 추천해줍니다.

https://antiplan.vercel.app/

## 기능

- 간단한 질문을 통한 칵테일 추천
- 취향에 맞는 칵테일 메뉴 확인
- 추천 결과에서 바로 주문할 메뉴 선택

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4
- React Hook Form
- Zod
- Supabase
- use-funnel
- Biome
